## GitHub

Mätänee päivä päivältä. Toiminnot (Actions) yksityisille kirjastoille maksullisiksi ja pian julkisetkin.

Kirjasto Githubiin

```bash
push an existing repository from the command line
git remote add origin https://github.com/Catventurist/ns-sivut.git
git branch -M cat
git push -u origin cat
```
