## Pääpiirteet

- Täysin **avoimella ja ilmaisella** lähdekoodilla rakennettu ja huolellisesti tarkastettu.
- Monikielisyys sisäänrakennettuna. 
  - [x] Suomeksi
  - [x] Englanniksi
  - [ ] Espanjaksi
  - [ ] Saksaksi
  - [ ] Ruotsiksi
- Selvää säästöä kun itse tekee.
  - Mahdolliset **palvelinkulut** pyritty minimoimaan.
  - Ei maksullisia lisäosia oletuksena.
- Luo vain sisältöä, automatiikka hoitaa loput.

## Pohja

[Nuxt](https://nuxt.com/) venyy melkolailla mihin vaan `modules`-lisäosineen.

+ [UI](https://ui.nuxt.com/) sisältää tarvittavat komponentit ulkoasuille.
  + Voi muokata mieleisekseen
  + Monipuoliset teeman säädöt
+ [Motion](https://motion.dev/) animaatiot sujuviin liikkeisiin.
+ [Content](https://content.nuxt.com/) sisällöille.
  + sisällönhallintaan, hakuihin, navigointiin ym.
  + `md`, `yml`, `csv` & `json`-tiedostomuodot laajennettavissa
+ [i18n](https://i18n.nuxtjs.org/) kaikkiin **käännöksiin**, reitteihin jne.
+ [Eslint](https://eslint.nuxt.com/) Koodin ulkoasun viilaamiseen
+ [VueUse](https://vueuse.org/) Näppärät koodirimpsut
+ [Fonts](https://fonts.nuxt.com/) Valinnaisia avoimen lähdekoodin **Bunny**-kirjaisimia
  - [x] Finlandica
  - [x] Arima Madurai
  - [x] Chivo Mono
  - [x] Caveat
+ [Icons](https://nuxt.com/modules/icon) Valitse kuvakekirjastoista
  - [x] Lucide
  - [x] Tabler
  - [x] Simple-icons
  - [x] VsCode-icons
+ [Image](https://image.nuxt.com/) Kuvien optimointi
  - webp/avif/png-tiedostomuodot
+ Tärkeimmät
  - /app/app.config.ts Sivuston asetukset
  - /nuxt.config.ts Alustan asetukset
  - /app/composables/useHeader.ts Sivuston linkit koostettuna
